# AIDA64 Keys

**This is for educational purposes only!**

The project contains methods for generating and verifying AIDA64 keys.

## ✨ Fork Changes

- Updated GitHub Actions workflow.
- Added Windows and macOS build artifacts.
- Linux build removed.

## 💻 Downloads

Precompiled binaries are available in the Releases section.

**[Download Latest Release](https://github.com/sarcandi/Aida64-Keys/releases/latest)**

### Available Builds

| Platform | File |
|----------|------|
| Windows | `Aida64-Keys-windows-latest.zip` |
| macOS | `Aida64-Keys-macos-latest.zip` |

Builds can also be found in [GitHub Actions](https://github.com/sarcandi/Aida64-Keys/actions).

## ⚠️ Compatibility

Tested version: **AIDA64 6.80.6210**

Newer versions are very unlikely to recognize or accept the key.

## 🛠️ Build Information

Builds are automated using GitHub Actions.

Supported platforms:
- Windows
- macOS

Linux is currently excluded from the build matrix due to dependency compatibility issues.

Each successful build uploads its executable as a separate downloadable artifact.
