# AIDA64 Keys

**This is for educational purposes only!**

The project contains methods for generating and verifying AIDA64 keys.

## ✨ Fork Changes

- Updated GitHub Actions workflow.
- Added Windows and macOS build artifacts.
- Removed Linux builds.

## 💻 Downloads

Precompiled binaries are available in the Releases section.

Builds can also be found in [GitHub Actions](https://github.com/sarcandi/Aida64-Keys/actions).

## ⚠️ Compatibility

Tested version: **AIDA64 6.80.6210**

Newer versions are very unlikely to recognize or accept the key.
